# SeedVerse

Minecraft universe mod, which enables traversal across every seed in the game with an OpenGL-rendered User Interface.

I don't have much time myself to develope this mod further at this time, as I have school to attend to,
so don't wonder why I'm not terminally locked in to update this.

Also it's worth noting, that OpenGL in minecraft will be deprecated, as it will be replaced with Vulkan in the future. So the graphics code should be rewritten eventually.

## Modrinth

Download the mod and check out the official page on **[Modrinth](https://modrinth.com/mod/seedverse)**.

## Features

- **Massive 3D Galactic Map:** Explore clusters, galaxies, and star systems.
- **Seed-Based Dimension Travel:** Every planet runs on its own unique world seed.
- **Social Features:** Multi-player map pings, player tracker, and chat space beacons.
- **Visual Shaders:** Custom GLSL shaders for celestial and black hole rendering.
